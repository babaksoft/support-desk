# Learning Record

Add a short record when a measured experiment or operational exercise yields a
useful conclusion. Include the question/hypothesis, compared configurations,
dataset/source versions, observations, cost/latency effects, limitations, and the
resulting decision. Link to reproducible evidence without committing sensitive data.

Code walkthroughs can stay in discussion unless they establish durable design
knowledge. This directory is not a requirement to write an essay for every change.
