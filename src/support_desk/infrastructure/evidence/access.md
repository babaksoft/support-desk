# Account access

Source ID: `BL-ACCESS`

Version: `1`

## Sign-in and password reset

Boardlight accounts use email and password sign-in. Use the email address associated
with the intended workspace membership.

From the sign-in page, select Forgot password and enter the account email address.
A reset link expires after 30 minutes and can be used once. Requesting a new reset
link invalidates earlier links. If an email is missing, check spam and confirm the
entered address. If access remains blocked, ask an operator to investigate.

## Invitations and missing workspaces

The workspace owner invites a member by email. An invitation expires after seven
days and must be accepted while signed in with the invited email address. The
owner can revoke an invitation or send a replacement; a replacement invalidates
the earlier invitation. An expired or revoked invitation releases its reserved
member slot. A replacement reserves one slot rather than adding a second.

If a workspace is missing from the switcher, check the signed-in email and whether
the invitation was accepted. Ask the owner to confirm membership or replace an
expired invitation. A plan upgrade changes workspace capacity; membership is
managed separately by the owner.

## Information for support

Provide the workspace ID if known, the affected account email, the attempted step,
and the visible error. Account emails used in this learning project are synthetic.
Keep passwords, reset links, and invitation links private.
